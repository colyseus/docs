Here you will find a guide on how to use the Frontend State Sync Callbacks with React.

<Callout type="warning">
    React hooks for state synchronization ship today as the separate [`@colyseus/react`](https://github.com/colyseus/react-tools) package: `useRoom`, `useRoomState`, `useRoomMessage`, `useLobbyRoom`, and friends. See [Getting Started with React](/getting-started/react) for usage.
</Callout>
