`@colyseus/database` is the recommended path, but Colyseus does not require it. Any database or Node.js module works. Query it directly from your room's lifecycle methods.

If you go this route, we still recommend [Drizzle ORM](https://orm.drizzle.team/) (what `@colyseus/database` is built on). Other commonly used tools:

## Backend-as-a-Service

[Firebase](https://firebase.google.com/) (Firestore / Realtime Database) is a common choice when you want managed persistence, authentication, and hosting without running your own database. Use the [Firebase Admin SDK](https://firebase.google.com/docs/admin/setup) from your server and call it from the room lifecycle methods below, just like any other database client.

## Usage patterns with Colyseus

### Query the database in `onAuth()`

Fetch user data from the join `options` the client sends, or from the authentication token.

```ts title="src/rooms/MyRoom.ts"
// db: your own client (pg, knex, prisma, ...)
async onAuth(client, options) {
    const user = await db.query('SELECT * FROM users WHERE id = ?', [options.userId]);
    return user;
}

async onJoin (client, options) {
    // ...
    await db.query('UPDATE users SET online = true WHERE id = ?', [client.auth.id]);
}
```

### Update the database in `onLeave()`

Update the database when the client leaves the room.

```ts title="src/rooms/MyRoom.ts"
// ...
async onLeave(client, consented) {
    // ...
    await db.query('UPDATE users SET online = false WHERE id = ?', [client.auth.id]);
}
```
