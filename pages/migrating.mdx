# Migrating between versions

Each guide covers the breaking changes and new APIs when upgrading from the previous version. Upgrade one major version at a time.

- [**Migrating to 0.18** (from 0.17)](/migrating/0.18) — built-in client-side prediction & lag compensation ([netcode](/netcode)), `setSimulationInterval` → `setTimestep`, `@colyseus/database` / `@colyseus/admin`, auth password-reset requirement.
- [**Migrating to 0.17** (from 0.16)](/migrating/0.17)
- [**Migrating to 0.16** (from 0.15)](/migrating/0.16)
- [**Migrating to 0.15** (from 0.14)](/migrating/0.15)

Upgrading from something older? Follow the guides in sequence — and the archived docs for each version remain available from the **Versions** menu above.
