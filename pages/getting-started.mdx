A Colyseus game has two parts: a server that runs your game rooms, and a client that connects to them. Set them up in this order.

<Steps>
### Create a server

Scaffold a Node.js server with one command, then add a first room to it. Every client SDK below connects to this server.

## 🤖 Using an AI coding agent

Most models learned Colyseus from material older than 0.18. Without guidance, they write `colyseus.js` imports, `Room<MyState>` generics and `client.id`. The [Colyseus skill](https://github.com/colyseus/skill) keeps the agent on the current APIs and has it check your installed version before writing any Room or Schema code. Install it for Claude Code, Codex, Cursor, Gemini CLI, Copilot or any other agent that supports skills:

``` bash filename="Terminal"
npx skills add colyseus/skill            # this project
npx skills add colyseus/skill --global   # every project
```

The skill activates on its own when a task involves Colyseus. Bundled docs cover the areas agents get wrong most (state, rooms, the client SDK, netcode), with links to the rest.

Without the skill, point the agent at [llms.txt](https://docs.colyseus.io/llms.txt). Every page is also served as raw markdown: append `.md` to its URL, e.g. [`/room.md`](https://docs.colyseus.io/room.md).
