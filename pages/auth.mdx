# Authentication

Colyseus authenticates clients on two surfaces: **room joins** (via an `onAuth` hook) and **HTTP routes** (via middleware). The official [`@colyseus/auth`](/auth/module) module powers both surfaces and pairs with [`@colyseus/database`](/database) for a zero-config user store, automatic route mounting, and revocation-aware sessions.

<Callout type="info">
    **Fastest setup:** add a `GameDatabase` to `defineServer` and `@colyseus/auth` wires itself — user store, register/login routes, ban gating, and revocation-aware JWTs, all from one option. → [Database → Authentication](/database#authentication-built-in-colyseusauth-integration)
</Callout>

## Common scenarios

<ScenarioGrid>
    <ScenarioCard icon={<SignInIcon size={18}/>} title="Authenticate a room join" href="/auth/room">
        Verify JWTs and reject revoked sessions in your room's <code>onAuth</code> hook. The database integration handles revocation automatically.
    </ScenarioCard>
    <ScenarioCard icon={<ShieldCheckIcon size={18}/>} title="Protect an HTTP endpoint" href="/auth/http">
        Gate any HTTP route behind a valid JWT with <code>auth.middleware()</code> — works for both Express handlers and the typed <code>createEndpoint</code> HTTP routes.
    </ScenarioCard>
    <ScenarioCard icon={<SignOutIcon size={18}/>} title="Revoke a session or force-logout" href="/database#authentication-built-in-colyseusauth-integration">
        Atomic ban with <code>tokenVersion</code> bump (existing JWTs invalidated), or call <code>bumpTokenVersion()</code> standalone for non-ban revocations like password change.
    </ScenarioCard>
    <ScenarioCard icon={<PackageIcon size={18}/>} title="Bring your own database" href="/auth/module#backend-api">
        Implement <code>@colyseus/auth</code>'s backend callbacks against your own storage. The <code>@colyseus/database</code> integration is optional — every flow works without it.
    </ScenarioCard>
    <ScenarioCard icon={<GlobeIcon size={18}/>} title="OAuth, anonymous login, password reset" href="/auth/module">
        200+ OAuth providers (Discord, Google, X, …), anonymous registration, and forgot/reset password flows with customizable email templates.
    </ScenarioCard>
    <ScenarioCard icon={<GearIcon size={18}/>} title="Customize individual callbacks" href="/database#customizing-callbacks">
        Override specific hooks (e.g. add an invite-code check on registration) while keeping the rest of the database integration intact.
    </ScenarioCard>
    <ScenarioCard icon={<DevicesIcon size={18}/>} title="Use the frontend client SDK" href="/auth/module#frontend-api">
        Typed client methods for register, sign-in (email/password, anonymous, OAuth), password reset, and sign-out. The auth token is sent automatically.
    </ScenarioCard>
</ScenarioGrid>
