# Authentication

Colyseus provides built-in tools to verify the identity of your clients — both at room-join time and on HTTP endpoints. You can use the official [`@colyseus/auth`](/auth/module) module, bring your own token validation logic, or — for the fastest path — combine `@colyseus/auth` with [`@colyseus/database`](/database) to get the user store, auth routes, and JWT revocation wired automatically.

<Callout type="info">
    **Recommended:** pass a `GameDatabase` to `defineServer` and the database becomes the user store, all auth routes mount automatically, and JWTs become revocation-aware. See [Database → Authentication](/database#authentication-built-in-colyseusauth-integration).
</Callout>
