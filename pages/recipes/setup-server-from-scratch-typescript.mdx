# Setup Server from Scratch with TypeScript

A step-by-step guide for creating a Colyseus server with TypeScript, without the project template. Prefer `npm create colyseus-app@latest` unless you need full control over every file.

## Requirements

- [<DownloadIcon/> Download and Install Node.js](https://nodejs.org/)

### Setup

Create a new empty directory.

```sh filename="Terminal"
mkdir colyseusServer
```

Go into the directory.

```sh filename="Terminal"
cd colyseusServer
```

Initialise npm with default options

```sh npm2yarn
npm init
```

Change the `"main"` and `"scripts"` property of the `package.json`.

```json filename="package.json"
{
  "main": "dist/main.js",
  "scripts": {
    "build": "tsc",
    "start": "tsx watch src/main.ts",
    "start:prod": "node dist/main.js"
  }
}
```

Install Dependencies

```sh npm2yarn
npm i colyseus
```

Install Dev Dependencies

```sh npm2yarn
npm i --save-dev typescript tsx
```

Create a new file called `tsconfig.json` in the root of the project

```json filename="tsconfig.json"
{
    "compilerOptions": {
        "outDir": "./dist",
        "target": "ESNext",
        "module": "CommonJS",
        "moduleResolution": "node",
        "strict": true,
        "allowJs": true,
        "strictNullChecks": false,
        "esModuleInterop": true,
        "experimentalDecorators": true,
        "skipLibCheck": true,
        "forceConsistentCasingInFileNames": true,
        "useDefineForClassFields": false
    },
    "include": [
      "src"
    ]
}
```

Create a new `src/rooms` directory

```sh filename="Terminal"
mkdir -p src/rooms
```

### State and Room

Define the synchronized state for your room.

<Tabs items={["Schema Builder", "Decorators"]} storageKey="schema-style">
    <Tabs.Tab>
    ```ts filename="src/rooms/MyState.ts"
    import { schema, t } from "@colyseus/schema";

    export const Player = schema({
        x: t.number().default(0),
        y: t.number().default(0),
    }, "Player");

    export const MyState = schema({
        players: t.map(Player),
    }, "MyState");
    ```
    </Tabs.Tab>
    <Tabs.Tab>
    ```ts filename="src/rooms/MyState.ts"
    import { Schema, MapSchema, type } from "@colyseus/schema";

    export class Player extends Schema {
        @type("number") x: number = 0;
        @type("number") y: number = 0;
    }

    export class MyState extends Schema {
        @type({ map: Player }) players = new MapSchema<Player>();
    }
    ```
    </Tabs.Tab>
</Tabs>

Create a room class that uses the state.

```ts filename="src/rooms/MyRoom.ts"
import { Room, Client } from "colyseus";
import { MyState, Player } from "./MyState";

export class MyRoom extends Room {
    state = new MyState();

    onJoin(client: Client) {
        this.state.players.set(client.sessionId, new Player());
    }

    onLeave(client: Client) {
        this.state.players.delete(client.sessionId);
    }
}
```

### Entrypoint

Create a new file called `main.ts` in the `src` directory. It registers the room type and starts listening.

```ts filename="src/main.ts"
import { defineServer, defineRoom } from "colyseus";
import { MyRoom } from "./rooms/MyRoom";

const port = parseInt(process.env.PORT, 10) || 2567;

const server = defineServer({
    rooms: {
        my_room: defineRoom(MyRoom),
    },
});

server.listen(port);
```

Congrats, you finished the setup for a Colyseus server. Clients can now join it via `client.joinOrCreate("my_room")` — see [Joining Rooms](/sdk#joining-rooms).

## Commands

Start the server in development with:

```sh npm2yarn
npm start
```

`tsx watch` automatically restarts the server when you change a file.

For production you first create a build.

```sh npm2yarn
npm run build
```

After that you can start the server with the `start:prod` command. This command uses the files which are created from the `build` command in the `dist` folder.

```sh npm2yarn
npm run start:prod
```
